# 调试台

一个网页版的上位机，把**串口调试**和 **DFU 烧录**放在同一个窗口里。

双击 `启动调试台.bat` 就能用，不装任何东西 —— 串口走浏览器的 Web Serial，烧录走 WebUSB，
两者都是 Edge / Chrome 内置的能力。

```
工具\调试台\
├── index.html        界面
├── style.css         样式
├── app.js            串口与 DFU 逻辑
├── 启动调试台.bat    起本地服务并用 Edge 独立窗口打开
└── README.md         本文件
```

## 为什么是网页

这台机器上 `pyserial` 和 `tkinter` 都装不上（网络拉不动包），而浏览器自带串口和 USB 访问能力。
做成网页还有一个好处：源码就是最终产物，改一行刷新就生效，不用重新打包。

代价是**只能用 Chromium 内核**（Edge / Chrome）。Firefox 不支持 Web Serial 和 WebUSB。

## 启动

双击 **`启动调试台.bat`**。

脚本会做三件事：

1. 从 8765 起找一个没被占用的端口
2. 用 Python 起一个只监听 127.0.0.1 的静态服务
3. 用 Edge 的 `--app` 模式打开，没有地址栏，看起来就是个独立程序

那个命令行窗口就是服务本身，**保持它开着**；用完关掉它，服务就停了。

> 为什么不能直接双击 `index.html`：浏览器规定只有 `https` 和 `localhost` 下的页面才能访问串口和
> USB，`file://` 打开会被拒绝。启动脚本起本地服务就是为了满足这个条件。

## 串口调试

### 接线

板子没有板载 USB 转串口，需要外接一个 USB-TTL 模块：

| USB-TTL | 板子 |
|---|---|
| TX | PA3（USART2_RX） |
| RX | PA2（USART2_TX） |
| GND | GND |

参数固定 **115200 8N1**，不需要流控。TX/RX 是交叉接的，别接反。

### 用法

1. 点 **选择串口**，在浏览器弹窗里挑 USB-TTL 那个设备（只需授权一次，之后下拉框里就有）
2. 点 **打开串口**
3. 按一下板子的复位键，终端里应该出现三行启动横幅：

```
==== Circuit Model Explorer (STM32F407VET6, bare-metal) ====
SYSCLK = 168000000 Hz, DAC fs = 500000 SPS, ADC fs = 500000 SPS, N = 4096
Ready. Type ? for help.
```

看到这三行说明固件在跑、波特率也对。之后就能发命令了。

### 固件支持的命令

命令不区分大小写，固件只看第一个字符，参数直接跟在后面，结尾要有回车换行。

| 命令 | 作用 | 例子 |
|---|---|---|
| `?` | 打印帮助 | `?` |
| `F<f>` | 设定 DDS 输出频率（Hz） | `F1000` |
| `A<vpp>` | 设定激励峰峰值（V） | `A2.0` |
| `M` | 测量当前输出的幅值与相位 | `M` |
| `H` | 打印当前频率下已知模型的 \|H\| | `H` |
| `K<k>` | 设定幅值校准系数 | `K1.002` |
| `C<v>` | 开环控制，让已知模型输出达到目标 Vpp | `C1.5` |
| `L` | 未知模型自主学习（26 点扫频 + 分类 + 参数） | `L` |

右侧面板把这八条做成了按钮和输入框，常用的频率、幅度还给了预设值。
「三点扫频」会依次发 100 Hz / 1 kHz / 10 kHz 的 `H`，用来看幅频趋势。

终端支持时间戳、清屏、保存日志（导成 `.txt`）。

## DFU 烧录

### 前提

1. **BOOT0 接 3V3**：板子上排第 1 针（丝印 `BT0`）用杜邦线接到旁边的 `3V3`，然后插 Type-C 或按复位
2. **装过 WinUSB 驱动**：浏览器要访问 USB 设备，设备必须绑 WinUSB。用 Zadig 给它装一次，
   选 `STM32 BOOTLOADER (0483 DF11)`，驱动选 WinUSB

判据：设备管理器里出现 `STM32 BOOTLOADER`，且设备能在这个页面被选中。

### 用法

1. 点 **连接 DFU 设备**，在弹窗里选 `STM32 BOOTLOADER`
2. 把 `Keil\Objects\CircuitModel.hex` 拖到虚线框里（或点击选择）
3. 点 **开始烧录**

流程是：擦除涉及的扇区 → 按 2048 字节一块写入 → 发空块结束传输 → 芯片自动复位重新枚举。

烧完要**拔掉 BOOT0 那根线**再复位，否则芯片会再次进入 DFU 而不是跑程序。

### 烧录失败怎么办

浏览器访问 USB 对驱动有硬要求：**设备必须绑 WinUSB**。如果设备被 STM32CubeProgrammer 之类
独占过，或者 Zadig 装成了 libusbK / libusb-win32，本页会连不上。用 Zadig 重选 WinUSB 装一次即可。

驱动暂时搞不定就换路线：ST-Link 接 SWD（PA13/PA14），Keil 里直接按 F8，不用动 BOOT0。

## 已知限制

- **只支持 Edge / Chrome**。Firefox、Safari 没有这两个 API。
- **串口按 UTF-8 解码**。固件输出全 ASCII，不受影响；如果以后改成二进制协议，需要加 HEX 视图。
- **不做回读校验**。ST 的 bootloader 在 `dfuDNLOAD-IDLE` 状态不接受 `DFU_UPLOAD`，
  回读会被 stall。现在的做法是每一块都 `GETSTATUS` 确认，返回非 OK 立即中断。
- **一次只能连一个串口**。多设备场景需要开多个窗口。
- 浏览器会缓存静态文件，改了 `app.js` 看不到效果就按 `Ctrl+F5` 强刷。

## 排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 顶部徽章显示「非安全上下文」 | 直接双击了 index.html | 用 `启动调试台.bat` 打开 |
| 顶部徽章显示「不支持 Web Serial / WebUSB」 | 用了 Firefox | 换 Edge 或 Chrome |
| 点「选择串口」没有弹窗 | 不是用户手势触发，或被策略拦截 | 直接点按钮，不要用脚本调用 |
| 打开串口报 `Failed to open` | 端口被别的程序占着 | 关掉串口助手、Keil 的 UART 窗口 |
| 终端全是乱码 | 波特率不对 | 确认 115200，且 GND 已接 |
| 中文里夹着 `◆` 方块 | 旧版逐块新建解码器，汉字被切断 | 页面强刷 `Ctrl+F5`；新版已改为流式解码 |
| 能收到但发命令没反应 | 结尾没带回车 | 勾上「回车换行」 |
| 弹窗里没有 STM32 BOOTLOADER | 没进 DFU 或没装驱动 | BOOT0 接 3V3 后复位；用 Zadig 装 WinUSB |
| 连接 DFU 报 `Access denied` | 驱动不是 WinUSB，或被独占 | 用 Zadig 重装 WinUSB，关掉 CubeProgrammer |
| 烧到一半报 `errERASE` | 扇区写保护 | 检查选项字节，或换命令行版重试 |
