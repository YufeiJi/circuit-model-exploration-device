# 电路模型探究装置

Circuit Model Exploration Device：基于 STM32F407VET6 的信号激励、幅相测量与二阶网络辨识实验项目。

[快速开始](#quick-start) · [文档导航](docs/README.md) · [实现与验证状态](docs/STATUS.md) · [参与维护](CONTRIBUTING.md)

> 本仓库整理保留原有工程与文档。下文编译和烧录状态来自历史记录，本次未重新上板验证；精度、耗时和分类结果需实测复核。设计报告不等于当前固件功能清单。

STM32F407VET6 纯寄存器实现（无 HAL、无 CubeMX）。产生正弦激励、测量幅相、辨识未知 RLC 网络的传递函数。

**第一次接触这个项目，先看 [从零到跑通教程](教程-从零到跑通.pdf)**，17 页，从硬件清单一路讲到五级测试和故障排查。

## 快速开始（5 步）

```
1. 接线      PA2→USB-TTL 的 RXD、PA3→TXD、GND→GND
2. 编译      双击 Keil\CircuitModel.uvprojx，按 F7
3. 烧录      断电 → BT0 接 3V3 → 插 Type-C → 按 NRST
             双击 工具\调试台\启动调试台.bat，切「DFU 烧录」拖入 hex
             拔电 → BT0 挪回 GND → 插电 → 按 NRST
4. 看串口    在调试台的「串口调试」页打开 115200 8N1，应打出三行启动横幅
5. 测        ? → F1000 → A1.0 → H     （H 应回 2.5257）
```

前三步的细节、每一步的判据、以及出错怎么办，都在教程里。

## 硬件要点

| 功能 | 引脚 |
|---|---|
| DAC 激励输出 | PA4 |
| ADC 测量输入 | PA0（输入保持在 **0–3.3 V**，避免过压） |
| 串口 USART2 | PA2(TX) / PA3(RX)，115200 8N1 |
| SWD 调试 | PA13 / PA14（可选） |
| USB DFU | PA11 / PA12，板载 Type-C |
| 启动模式 | BOOT0（BT0 针）：GND 运行、3V3 进 DFU |

板子左边那个 `TX1/RX1` 4 针座是 **USART1，不能用**，本固件走 USART2。

## 常用命令

```
?            帮助
F1000        设频率 1000 Hz（100 ~ 100000）
A1.0         设激励 1.0 Vpp（0 ~ 2.70）
M            测当前输出的幅度与相位
H            打印当前频率下已知模型的理论 |H|
K1.032       设校准系数
C1.0         开环控制：让已知模型输出达到 1.0 Vpp
L            未知模型辨识（26 点扫频；耗时待上板复核）
```

## 已知模型（用于自检）

H(s) = 5 / (1e-8·s² + 3e-4·s + 1)，即 K = 5、f<sub>n</sub> = 1591.5 Hz、Q = 1/3。

在 1 kHz 处 |H| = **2.5257**（8.05 dB）—— 串口发 `H` 能对上这个数，说明浮点、数学库、printf 全部正常。

元件清单与搭法见 `教程-从零到跑通.pdf` 附录 B。

## 三个容易踩的坑

1. **改 `CircuitModel.uvprojx` 前必须先关 Keil**，否则 Keil 保存时会把磁盘上的改动覆盖掉。
2. **烧完必须把 BOOT0 挪回 GND**，否则芯片停在 bootloader 里，程序不跑、串口全静。
3. **打开现有工程无需重新安装器件包**，器件头与启动文件已提供。从零建工程请按指南使用匹配的 2.17.0 版本，勿直接套用其他包版本的目录结构。

## 克隆后的环境准备

使用 Windows、Keil µVision 5 与 ARM Compiler 6。当前工程的头文件与启动文件已随仓库提供。打开 [Keil 工程](Keil/CircuitModel.uvprojx) 后构建；`Objects`、`Listings` 与 `_verify` 由本机生成，不随仓库提交。SWD 烧录算法路径需按本机安装位置重新配置。

串口调试与网页版烧录见 [调试台](工具/调试台/README.md)；DFU 依赖及跨电脑运行方式见 [工具说明](工具/README.md)。建议显式指定刚构建的 HEX；原批处理和自动搜索仍包含历史机器路径。串口每条命令使用回车或换行结束。PA0 输入应保持在 0–3.3 V，接入被测网络前确认偏置和幅度。
