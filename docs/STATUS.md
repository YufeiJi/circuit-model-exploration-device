# 当前实现与验证边界

以 `Keil/Core`、`Keil/BSP`、`Keil/App` 为当前固件依据，`firmware/` 中本地导出的历史 HEX 不代表当前源码构建结果。

| 项目 | 当前情况 |
|---|---|
| 主控 | STM32F407VET6，寄存器实现 |
| 激励 | PA4，DDS，DAC 更新率 1 MSPS；幅度范围以当前 DDS 源码和实测标定为准 |
| 测量 | PA0，500 kSPS，4096 点，Hann 窗单频 DFT |
| 相位 | 相对于采集窗口起点，不能直接当作输入与输出传递相位 |
| 辨识 | 26 点扫频；对数幅值残差拟合四种二阶模型；120×80 网格及局部细化 |
| 参数搜索 | f0 为 5–50.3 kHz，Q 为 0.01–1；超出此范围的网络不保证可辨识 |
| 控制 | 已知模型开环幅度反算；不是闭环稳幅 |
| OLED 与按键 | 本地开发中的功能；发布状态以已提交源码为准，不能将硬件评审图视为实现证明 |
| 其他扩展 | 量程切换、第二 DAC 推理输出等不能视为当前固件已实现 |

原 README 记录编译零错误、零警告以及 DFU 烧录通过，同时注明串口及五级测试待验证。教程部分段落却使用了回环“实测”及精度结论，彼此不一致。没有附带可追溯测量数据时，这些数值应视为待复核的历史描述。本次仓库整理不构成硬件复测，也不确认耗时、精度或分类成功率。

已知模型为 `H(s)=5/(1e-8*s²+3e-4*s+1)`。`H` 命令仅计算理论增益；算对理论值不代表 ADC、DAC 或模拟电路已通过测试。

## 换电脑使用

- Keil Flash Download 设置含原机器路径，需要重新选择工程内 `Keil/Flash/STM32F4xx_512.FLM` 对应的烧录算法。
- DFU 批处理保留了原机器 Python 路径，默认固件搜索也包含本机绝对路径。新电脑推荐安装 Python 依赖后，用命令显式指定刚构建的 HEX，避免搜索到其他工程产物。
- 旧文档保留原貌。遇到版本冲突，先核对当前源码、工程设置与本说明。
