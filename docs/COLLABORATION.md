# 私有仓库添加协作者

1. 使用仓库所有者账号打开 GitHub 仓库。
2. 点击 Settings，在左侧 Access 下选择 Collaborators；如提示则完成身份验证。
3. 点击 Add people，输入对方 GitHub 用户名或邮箱，核对账号后发送邀请。
4. 对方登录对应账号并接受邀请后，即可访问私有仓库。仅发送仓库链接不会自动授予权限。

个人账号仓库的协作者通常具有读写权限，可以克隆和推送；邀请前确认对象。需要按只读等细分角色管理时，考虑使用组织仓库。可在同一设置页取消邀请或移除协作者。

[GitHub 官方操作说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/inviting-collaborators-to-a-personal-repository)
